What it does

Built for real drive diagnostics

Whether you are checking a suspicious disk, recovering data or testing heads, ATA Scanner Pro keeps every drive in its own workspace.

▦

Parallel scan slots

Select several physical drives and scan them at the same time. Switch between maps, statistics and graphs with the scan list.

◉

Sector latency map

Each block is coloured by read/write time so slow or unstable areas are easy to spot at a glance.

♥

S.M.A.R.T. viewer

Attributes, current/worst/threshold values, raw data, temperature, power-on hours, firmware and a clear health verdict.

⌁

Per-head testing

Read-only “Test head” mode samples each reported head separately and labels results H0, H1, and so on.

↻

Remap support

Rewrites unreadable sectors so the drive firmware can reallocate them. Use carefully and only on drives you own.

⌘

ATA Script runner

Parse-only dry run, then send raw ATA task-file registers through SMART IOCTL or ATA pass-through with full logging.

Documentation

Getting started

Short guide for first-time users.

01

Requirements

  • Windows PC
  • Run the EXE as Administrator
  • Directly attached SATA/ATA disk for low-level commands
  • Disk images can also be opened for scanning
02

Choose drives

Use Select all, pick individual disks, refresh the list or open a disk image. Then press Start scans.

You can add more scans while others are already running.

03

Pick a scan mode

  • Read (verify) — non-destructive surface test
  • Write (test pattern) — destructive
  • Erase (zeros) — destructive
  • Test head — read-only per-head sampling
04

I/O selector

API (DMA) is the standard Windows path. PIO (ATA pass-through) sends task-file commands through the Windows storage driver.

USB/RAID controllers often block raw ATA registers.

05

Review results

Use the scan list arrows to move between drives. Save a report for the current drive when finished.

06

Advanced tools

S.M.A.R.T. opens health details. ATA Script... lets advanced users run parsed register scripts.

Raw ATA commands can destroy data or brick a drive. Use only if you understand the command bytes.
